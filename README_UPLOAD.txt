全国病院マップ v29｜医療活動3軸・日本語UI版

【基礎データ】
- 施設数：97,393施設
- 地域数：1,880地域
- 診療科正規化：利用ベース 99.16%
- 診療科正規化マスター：v26

【v29の主な更新】
1. 医療活動を3軸へ分解
   - 手術型：手術件数の地域活動量
   - 救急型：救急車受入件数の地域活動量
   - 入院型：DPC患者数の地域活動量
   - 医療活動総合：手術35%・救急30%・入院35%を基本重みとして合成

2. 医療活動内部の欠測補正
   - 欠測した要素を「活動量が低い」とは扱わない
   - 取得できた要素だけに基本重みを再配分
   - これに合わせて「現在供給 3.0」も再計算
   - データ充足率を保持し、低充足地域を判別可能

3. 医療活動3軸をサイト全体へ展開
   - 地図指標
   - 地域詳細
   - 現在供給プロファイル
   - 1施設のカルテ（所在地地域情報）
   - 地域ランキング
   - CSV出力

4. 画面表記を日本語中心へ変更
   - CURRENT SUPPLY → 現在供給
   - ACTIVITY → 医療活動
   - STRUCTURE → 構造供給
   - EQUIPMENT → 画像診断装置
   - BED FUNCTION → 病床機能
   - SPECIALTY → 診療科
   - DATA QUALITY → データ充足率／データ品質
   - 全国P → 全国パーセンタイル
   ※ MRI、CT、DPC、CSV、URL、CODH、Geoshape、TopoJSON等の標準略語・固有名詞は維持

5. 指標選択の既存不整合を修正
   - 手術 / 10万人
   - 救急車 / 10万人
   - DPC患者 / 10万人
   - MRI / 10万人
   - CT / 10万人
   上記が実データ項目へ正しく接続するよう修正

【欠測監査の概要】
- 医療活動データあり：1,293地域
- 医療活動データなし：587地域
- DPC既知件数が欠測だが手術または救急が取得済み：78地域
- 医療活動総合がv28から0.25超変化：27地域
- 現在供給3.0がv28から0.25超変化：5地域
- 最大変化：約0.518（上板町）

【重要な解釈】
- MRI・CT、DPC、手術、救急等は現段階では主として地域集計です。
- 「1施設のカルテ」内に表示する地域指標は、施設そのものの実績と誤認しないよう「所在地地域の情報」として表示します。
- 別マスターで施設別MRI/CT詳細が揃った場合、施設カルテへ直接統合できる構造です。

[v30 病床精密化]
・医療情報ネット 2026-06-01 病院施設票から、一般病床・療養病床・精神病床の実数を市区町村単位で統合。
・画面上で「病床種別の実数」と「病床機能の既存指標」を明確に分離。
・高度急性期・急性期・回復期・慢性期の機能別実病床数は、病床機能報告の施設別データ統合後に置換予定。現時点では推測で補完しない。

[v31 人口分母最適化]
・施設、病院、手術、救急、DPC患者、MRI、CT、病床種別の画面表示を原則「人口1万人あたり」へ統一。
・在宅は65歳以上1万人あたりを基本とし、75歳以上1万人あたり指標を追加。
・診療科密度は既存比較との連続性のため人口10万人あたりを維持。
・人口1万人未満は「参考値」、1万人以上3万人未満は「注意」と表示。
・地図に人口規模フィルター（1万/3万/5万/10万人以上）を追加。
・小人口地域を除外して比較できるようにし、人口あたり指標の暴れを視覚的に抑制。
