全国病院マップ v35 — GitHub Pages 確認用
=====================================

このZIPの中身を、そのままGitHubリポジトリの公開対象フォルダ直下へアップロードしてください。
index.html が公開URLの入口です。

推奨確認項目
1. トップ画面で「地域を探す / 施設を探す / 診療科から見る / 需給・ランキングを見る」が切り替わる
2. 都道府県→市町村を選ぶと地域面が表示される
3. 施設ピン→「1施設のカルテ」が開く
4. MRI・CT保有施設では装置区分が表示される
5. 地域詳細、診療科分析、ランキングが開く
6. iPhoneでメニュー開閉、スクロール、モーダルの閉じる操作を確認
7. CSV出力を確認

GitHub Pages設定例
Settings → Pages → Deploy from a branch
Branch: main / root
公開後はキャッシュの影響があるため、更新直後に古い画面が出る場合は再読み込みしてください。

注意
・index.html と regions_v35.js / equipment_v33.js / v13_01.js〜v13_05.js は同じ階層に置いてください。
・ファイル名は変更しないでください。


v36確認項目
-----------
1. 市町村 / 区を選択 → 診療科分析を開く
2. 「内科（総合）」以外（例：整形外科）を選択
3. 選択直後に内容が切り替わること
4. 「選択した診療科を表示」でも反映されること
5. 「この診療科を地図で表示」で地図へ戻れること
6. 「閉じる」で確実に閉じること
7. 背景タップでも閉じること
8. 地域ランキングで指標・人口条件を変更し、反映されること
9. ランキングの閉じる / 背景タップを確認
10. 地域詳細 / 施設カルテ / 出典も閉じる操作を確認

GitHubへ上げる際は、旧 regions_v35.js を残しても動作上問題はありませんが、
公開版では regions_v36.js を含むv36 ZIP全体で上書きすることを推奨します。


v37追加確認
-----------
1. 「地域を探す」で指標を切り替え、「この指標の大本」が連動して変わる
2. サイドバー上部「データの大本・定義」から出典画面を開ける
3. 出典画面冒頭の「指標の大本｜早見表」が読める
4. 「需給・ランキング」で指標を変えると大本データも変わる
5. 「診療科から見る」で、標榜診療科 + IPSS人口の出典表示がある
6. iPhoneでメニューを開いた際、地図側のボタンや地域分析表示がメニューの前面に重ならない
7. 地域詳細の主要4カードがiPhoneで2×2表示になる
