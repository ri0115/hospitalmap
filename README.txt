全国病院MAP HTML v05

主な更新
- 都道府県選択を修復：fetch(JSON)を廃止し、ローカルHTMLでもGitHub Pagesでも動くJSデータ読み込みへ変更
- 病院＝青 / 有床診療所＝オレンジ / 無床診療所＝緑
- ピン表示：CLUSTER / INDIVIDUAL 切替
- 在宅 ON/OFF、地域包括 ON/OFF をワンタップ化
- 在宅・地域包括の詳細区分フィルターを維持
- 診療科入力フィルター（部分一致）
- 並び替え：施設名、保険指定年の古い/新しい順、病床数、診療科数、診療科名
- 「指定から10/20/30/50/70年以上」フィルター
- 「指定50年以上」件数を表示

重要
「保険指定年」は施設の実開設年ではありません。
現データでは厚生局の保険医療機関指定年月日を利用しています。
実開設年月日を追加した段階で設立年ベースへ切替可能です。

使い方
ZIPを展開し、index.html と data フォルダの位置関係を変えずに開いてください。
地図タイルとLeaflet本体はインターネット経由で読み込みます。
